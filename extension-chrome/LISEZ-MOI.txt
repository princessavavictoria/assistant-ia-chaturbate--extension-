Chère Ava, j'ai créé cette version spéciale de l'extension pour résoudre TOUS les problèmes d'installation.
Vous n'avez plus besoin d'installer Node, de taper des commandes compliquées ou de compiler du code !
Tout est déjà pré-configuré et prêt à l'emploi.

------------------------------------------------------------------------
👉 ÉTAPE 1 : TÉLÉCHARGER ET DÉCOMPRESSER LE CODE
------------------------------------------------------------------------
1. Dans l'interface de Google AI Studio, cliquez en haut à droite sur le bouton d'engrenage (Settings) ou "Export" -> cliquez sur "Export to ZIP" (Exporter en ZIP).
2. Téléchargez le fichier ZIP sur votre ordinateur (sur votre Bureau ou dans vos Documents).
3. Faites un clic droit sur le fichier ZIP téléchargé et choisissez "Extraire tout" (Extract all) ou "Décompresser".

------------------------------------------------------------------------
👉 ÉTAPE 2 : INSTALLER L'EXTENSION DANS GOOGLE CHROME
------------------------------------------------------------------------
1. Ouvrez votre navigateur Google Chrome.
2. Dans la barre d'adresse, tapez : chrome://extensions/   puis appuyez sur Entrée.
3. En haut à droite de cette page, activez le bouton "Mode développeur" (Developer mode).
4. En haut à gauche, cliquez sur le bouton "Charger l'extension non empaquetée" (Load unpacked).
5. Dans la fenêtre qui s'ouvre, allez dans le dossier que vous venez de décompresser, et sélectionnez le dossier nommé :
   👉  extension-chrome  👈
6. Cliquez sur "Sélectionner le dossier".

C'est fini ! L'extension "CB AI Assistant (Direct Web)" apparaît maintenant dans votre liste d'extensions ! 🎉

------------------------------------------------------------------------
👉 ÉTAPE 3 : UTILISATION ET PARAMÈTRES
------------------------------------------------------------------------
1. Épinglez l'extension à votre barre d'outils Chrome (cliquez sur l'icône en forme de pièce de puzzle en haut à droite de Chrome, puis cliquez sur l'épingle à côté de "CB AI Assistant").
2. Allez sur Chaturbate (votre salon de show ou n'importe quel salon de test).
3. Cliquez sur l'icône de l'extension : le panneau latéral (Sidebar) s'ouvrira automatiquement à droite de votre écran !
4. La première fois, l'extension vous demandera votre clé API Gemini (pour l'IA) :
   - Entrez simplement votre clé API Gemini et cliquez sur Enregistrer.
   - Votre configuration Firebase est déjà pré-enregistrée et activée automatiquement !
